# 📖 Overview

This project is a **frontend clone of Netflix's landing page**, developed entirely with **HTML5 and CSS3**.

The goal of this project was to practice modern web development fundamentals including responsive layouts, Flexbox, CSS Grid, positioning, animations, and component-based page structure without using JavaScript or any frontend framework.
